# 🌐 Aarav Patel | Personal Developer Portfolio

Welcome to the source code repository for my personal developer portfolio website! Hosted via **GitHub Pages**, this site acts as my central digital hub to showcase live software engineering projects, track my technical stack interests, and link out to my external coding profiles.

🔗 **Live Site:** [https://GoogleHub67.github.io](https://GoogleHub67.github.io)

---

## 🚀 Features & Modules

- 💻 **Project Showcase** – A curated gallery of my live software engineering projects with source links.
- 🛠️ **Tech Stack Tracker** – A visual breakdown of my current technical proficiencies and interests.
- 📊 **GitHub Stats Integration** – Dynamic rendering of my open-source contribution metrics.
- 📱 **Responsive Design** – Fully optimized for a seamless viewing experience across mobile, tablet, and desktop viewports.

---

## 📁 Repository Structure

The project is structured logically across modular directories to separate configurations, styling, and data:

* `_data/` – Custom data files steering the site's dynamic content.
* `configs/` – System and site-wide configuration properties.
* `interactive-modules/` – Interactive components and frontend scripts.
* `prj/` – Interactive repositories and their details.
* `skills/` – Conceptual mapping of my skills and hobbies.
* `index.html` – The core entry point for the single-page application profile.
* `styles.css` – Global stylesheet defining the visual look, feel, and theme.

## 🛠️ Local Development

To run this portfolio website locally on your machine for testing or custom modification, follow these quick steps:

### 📋 Prerequisites
A standard modern web browser (e.g., Chrome, Firefox, Safari) is all you need. If you intend to use a local development server for tracking asset changes perfectly, ensure you have **Node.js** or **Python** installed.

### 🔧 Setup & Running

1. **Clone the repository:**
   ```bash
   git clone https://github.com/GoogleHub67/GoogleHub67.github.io
   cd GoogleHub67.github.io
   ```

2. **Launch a local server:**
   
   *Using Python 3.x:*
   ```bash
   python -m http.server 8000
   ```
   *Using Node.js (via `serve` package):*
   ```bash
   npx serve .
   ```

3. **View the site:**
   Open your browser and navigate to `http://localhost:8000` (or the port specified by your node server).
