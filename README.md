# Personal Developer Portfolio 🌐

Welcome to the source code repository for my personal developer portfolio site! This website serves as a centralized hub to showcase my software engineering projects, technical stack interests, and professional links. 

The site is built with clean, lightweight front-end code and is automatically deployed and hosted globally via **GitHub Pages**.

## 🚀 Live Demo

You can visit the live website here: **[googlehub67.github.io](https://GoogleHub67.github.io)**

## 📂 Repository Layout

The project maintains a streamlined footprint for lightning-fast loading speeds:
```text
└── GoogleHub67.github.io/
    └── index.html         # Main entry point containing structural layout, styling, and portfolio data
```

## 🛠️ Features & Built With

* **Pure Semantic HTML5 / CSS3:** Structured cleanly without heavy external framework overhead to maximize performance.
* **Responsive Web Design:** Adapts smoothly across desktop monitors, tablets, and mobile screens.
* **Centralized Hub:** Showcases core engineering toolsets (Python, Scala, SQL, TypeScript) and links out to primary profiles like Chess.com, YouTube, and secondary project repositories.

## ⚙️ Local Development

If you want to view or tweak the website locally on your computer:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/GoogleHub67/GoogleHub67.github.io
   cd GoogleHub67.github.io
   ```

2. **Launch the site:**
   * Simply double-click `index.html` to open it directly in any modern web browser.
   * Alternatively, use the VS Code **Live Server** extension for real-time hot-reloading as you edit.
